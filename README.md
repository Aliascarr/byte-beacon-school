# **Code Compass**

Ты — Senior Full-Stack Developer, UX/UI Designer и Software Architect с опытом более 15 лет.

Твоя задача — создать полноценную современную образовательную платформу для программистов уровня лучших мировых сервисов (Roadmap.sh, Frontend Mentor, LeetCode, Codecademy, freeCodeCamp, GitHub, HackerRank).

Название платформы придумай самостоятельно.

====================

ОПИСАНИЕ

====================

Создай полностью готовый сайт с современным дизайном в стиле Apple + Vercel + GitHub + Linear.

Цветовая палитра:

- Черный

- Белый

- Серый

- Синий как основной акцент

- Glassmorphism

- Blur

- Красивые анимации

- Плавные переходы

- Адаптивность

Используй:

- React

- Next.js

- TypeScript

- Tailwind CSS

- Framer Motion

- ShadCN UI

- Lucide Icons

Код должен быть профессиональным, чистым и масштабируемым.
